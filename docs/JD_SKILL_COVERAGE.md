# TresVista Data Intelligence — Skill Coverage

This project is intentionally scoped to the prerequisites in the TresVista Analyst — Data Intelligence Group job description. No additional resume skill categories are being added.

## 1. Data Gathering, Cleansing and Normalization using Python
- Ingest retail source files.
- Standardize dates, categories and text fields.
- Remove duplicates and handle missing/invalid values.
- Produce a data-quality report.

## 2. ETL Processes
- Extract raw retail data.
- Transform and validate it with Python.
- Load clean dimensional tables into the relational database.

## 3. Power BI
- Build the stakeholder-facing dashboard from the curated analytical tables.
- KPI cards, trends, product/customer/region analysis and forecast views.

## 4. DBMS Fundamentals
- Primary and foreign keys.
- Constraints.
- Normalized dimension/fact design.
- Transactions and referential integrity.

## 5. SQL: Joins, Views, Triggers, Window Functions and CTEs
- Multi-table joins for business analysis.
- CTEs for readable analytical queries.
- Window functions such as LAG, RANK and running calculations.
- Views for reusable reporting datasets.
- Triggers for data/audit integrity workflows.

## 6. Analytical, Problem-Solving and Communication Skills
- Translate business questions into KPIs.
- Explain findings in business language.
- Provide concise recommendations based on the analysis.
- Document assumptions, data-quality decisions and results.

## 7. Data Engineering using Python / Spark / Databricks / Snowflake
- Python is the primary engineering language.
- The pipeline is structured as reusable ETL modules.
- PySpark is the scalable-processing extension; Databricks and Snowflake are not required for this project.

## 8. Basic Generative AI Concepts
- Include a small natural-language-to-SQL concept for asking business questions against the curated database.
- Keep the GenAI component intentionally basic; it is not the main project focus.

## 9. Analytics Domain Experience
- Retail sales analytics.
- Customer, product, regional and time-based performance analysis.
- Demand forecasting and business recommendations.

## 10. Relational Database Design and Optimization
- Star-schema dimensional modeling.
- Appropriate keys and constraints.
- Indexes on commonly joined/filtering columns.
- Reusable SQL views for analytical access.

## Scope rule
The implementation should demonstrate these ten prerequisite areas without turning the project into a collection of unrelated technologies. The retail dataset remains the center of the project, and every component must support the same end-to-end business workflow.
